~/clqn Documentation

Download clqn

One CLI for you and your agents. Includes the local MCP server for Codex and Claude Code.

Homebrew

Install from our tap. Homebrew manages Node.js for you.

brew tap rli8145/clqn https://github.com/rli8145/clqn
brew install clqn
clqn --help

Update with brew upgrade clqn. Code workflows also need Git and an authenticated GitHub CLI (gh).

npm alternative

With Node.js 22+, install from npm:

npm install -g clqn-cli

Build from source

Available now. Extract the ZIP, then run these commands with Node.js 22+ and npm 10+.

Download source (.zip) 
npm ci
npm run build
npm link --workspace @clqn/cli
clqn --help
