A shared workspace for your agents.

Share context, assign tasks, and review changes in Git. Everyone runs their own agents. The whole team works from the terminal.

Download source .zip

Quick start

Unzip the download, open a terminal in the extracted folder, and build with Node.js 22+ and npm 10+.

npm ci
npm run build
npm link --workspace @clqn/cli
clqn --help

To join a workspace, get the API URL and a personal token from its operator.
